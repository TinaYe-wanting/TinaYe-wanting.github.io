# Tina Ye｜个人求职主页

这是一个面向实习招聘者的个人电子名片网站，用于展示我的教育背景、技能、学生工作与比赛经历。

## 网站链接

https://tinaye-wanting.github.io/

## 模板来源

本项目基于 [modern-resume-theme](https://github.com/sproogen/modern-resume-theme) 模板开发，并根据个人求职展示需求进行了内容与视觉修改。

## 主要修改内容

- 替换为个人姓名、学校、专业和求职定位；
- 展示 Office 工具、AI 工具应用与金融知识学习方向；
- 展示院学生会团委义工部部长经历；
- 展示国创赛国际区域赛铜奖及 APEC 视频大赛经历；
- 使用蓝色与浅蓝色色块、圆角卡片优化页面视觉；
- 增加首页 `GO` 按钮，用于跳转至经历区块；
- 优化桌面端和手机端的阅读体验。

## 项目结构

```text
docs/          PRD、Design、Checklist
report/        最终报告
screenshots/   验收截图
```

## 本地预览

本项目使用 Jekyll 和 GitHub Pages。若需本地运行，请安装 Ruby、Bundler 与 Jekyll 后执行：

```bash
bundle install
bundle exec jekyll serve
```

## 隐私说明

仓库不包含密码、API Key、Token、`.env` 文件、电话、身份证号或其他不应公开的个人信息。
