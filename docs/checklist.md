# 个人网站验收清单

## 1. 内容验收

- [1] Hero、About、Skills、Projects、Contact 五个区块齐全。
- [1] 首屏展示姓名。
- [1] About 中展示真实院校、专业和个人简介。
- [1] Skills 中的技能、工具和兴趣方向真实。
- [1] Projects / Experience 中至少有一项真实学校经历、比赛经历或“个人网站开发项目（进行中）”。
- [1] 没有保留模板作者姓名、示例经历或占位文字。
- [1] 未公开电话、身份证号、住址等私人信息。

## 2. 功能验收

- [1] 页面导航可以跳转到对应区块。
- [1] GitHub 主页链接可点击并能打开。
- [1] Contact 中的其他公开链接可正常打开。
- [1] 首屏按钮可点击并跳转到正确位置。

## 3. 显示验收

- [1] 在电脑浏览器中页面文字清晰，无重叠、遮挡或横向滚动。
- [1] 在手机浏览器中页面文字清晰，图片不超出屏幕。
- [1] 手机端导航、按钮和链接可以正常使用。
- [1] 页面颜色、字体和间距风格统一。

## 4. 工程与过程验收

- [ ] README.md 已写明项目名称、模板来源、主要修改内容、GitHub Pages 链接和隐私说明。
- [1] docs/prd.md 已完成，且与最终网站一致。
- [1] docs/design.md 已完成，且与最终网站一致。
- [1] docs/checklist.md 已完成。
- [1] GitHub 仓库至少有 3 次有意义的 Commit。
- [1] 仓库中不包含密码、API Key、Token、.env 或无关的大文件。

## 5. 发布与证据验收

- [1] GitHub Pages 已成功发布。
- [1] GitHub Pages 链接可在无痕窗口打开。

- [1] 已保存 Pages 公开页面或部署成功截图：screenshots/github-pages.png。
