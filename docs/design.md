# 个人网站 Design

## 1. 页面结构与浏览顺序

页面从上到下依次为：

1. Hero：首页首屏，展示姓名和“GO”按钮。
2. About：展示学校、专业、年级和简短个人介绍。
3. Skills：展示技能和兴趣方向。
4. Projects / Experience：展示学校经历、比赛经历和个人项目。
5. Contact：展示 GitHub主页链接。

## 2. 视觉风格

- 整体风格：线条干净，整体简约现代风格
- 主色：白色
- 辅助色：深蓝色
- 字体要求：字体为楷书，清晰易读，标题和正文有明显层级。
- 页面重点：可快速看到姓名、院校、专业和经历。

## 3. 桌面端与手机端要求

- 桌面端：导航、文字和经历内容清晰，页面不出现遮挡或横向滚动。
- 手机端：文字可读，图片不超出屏幕，区块按顺序显示，按钮可点击。
- 所有链接在电脑和手机端均可使用。

## 4. 文件修改边界

- 保留模板原有的技术栈和 GitHub Pages 发布方式。
- 优先修改模板中与个人资料、经历、颜色和页面布局有关的文件。
- 不更换框架，不新增无关依赖。
- 不公开电话、身份证号、住址等私人信息。

## 5. 图片与素材

- 个人照片：不使用
- 图标/图片来源：暂不使用外部图片
- 所有素材应允许公开使用。
