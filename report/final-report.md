# 个人网站最终报告

## 1. 项目定位

本项目是一个面向实习招聘者的个人电子名片网站，用于展示我的教育背景、技能、学生工作与比赛经历。

目标访问者可以快速了解我的姓名、学校、专业、实践经历和公开项目链接。

## 2. 模板选择

本项目基于 modern-resume-theme 模板开发。

选择该模板的原因是：它支持 GitHub Pages 发布，适合简历与经历展示，结构清晰，能够在保留原有技术栈的基础上完成个人化修改。

## 3. 主要修改内容

- 替换模板默认姓名、经历、技能和社交信息；
- 加入深圳大学信息管理与信息系统专业相关介绍；
- 展示 Office 工具、AI 工具应用、金融知识学习与 CFA 学习方向；
- 展示院学生会团委义工部部长经历；
- 展示国创赛国际区域赛铜奖和 APEC 视频大赛经历；
- 增加首页 `GO` 按钮，跳转至经历区块；
- 使用皇家蓝、浅蓝和深灰配色，增加圆角色块与卡片布局；
- 保留 Projects 区的网站链接；
- 完成桌面端与手机端适配。

## 4. AI 协作与个人判断

AI 协助我理解模板结构、制定修改步骤、生成 PRD、Design、Checklist、README 与最终报告的初稿，并协助排查 GitHub Pages 和页面样式问题。

我本人决定了网站面向实习招聘者的定位、公开内容范围、经历与技能表述、配色风格、页面布局和最终验收标准。
